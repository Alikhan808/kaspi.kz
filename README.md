# Kaspi.kz — учебный клон интерфейса

Учебный проект: воссоздание части интерфейса приложения Kaspi.kz (React + Vite).

## Что реализовано

1. **Главный экран** — поиск, промо-баннеры, сетка сервисов (Магазин, Мой Банк, Госуслуги и т.д.), нижняя навигация.
2. **Экран «Госуслуги»** — открывается по нажатию на иконку «Госуслуги» на главном экране. Список услуг с вкладками «Все услуги» / «Мои заявки».
3. **Экран «Удостоверение личности»** — открывается по нажатию на карточку/строку «Удостоверение личности». Позволяет загрузить фото документа с телефона/компьютера. Фото сохраняется в `localStorage` браузера — оно останется после перезагрузки страницы.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
```

Соберёт статику в папку `dist/`.

## Деплой на Vercel

**Вариант 1 — через сайт vercel.com (проще всего):**
1. Зайди на [vercel.com](https://vercel.com) и залогинься.
2. Загрузи эту папку как новый проект (Import Project → Upload), либо залей код в GitHub-репозиторий и подключи его через "Add New Project".
3. Vercel сам определит фреймворк (Vite) — настройки по умолчанию подойдут:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Нажми Deploy.

**Вариант 2 — через Vercel CLI:**
```bash
npm i -g vercel
vercel
```
Следуй подсказкам в терминале.

## Важно про сохранение фото

Фото хранится в `localStorage` **именно в том браузере**, где было загружено — оно не отправляется на сервер и не видно другим пользователям сайта. Это нормально для учебного проекта: полноценное серверное хранилище потребовало бы базы данных и бэкенда.

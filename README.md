# Kaspi.kz — учебный клон интерфейса

Учебный проект: воссоздание части интерфейса приложения Kaspi.kz (React + Vite).

## Что реализовано

1. **Главный экран** — поиск, промо-баннеры, сетка сервисов с иконками в фирменном заполненном стиле (Магазин, Мой Банк, Госуслуги и т.д.), нижняя навигация. Без имитации статус-бара телефона (время/батарея убраны).
2. **Экран «Госуслуги»** — открывается по нажатию на иконку «Госуслуги» на главном экране. Список услуг с вкладками «Все услуги» / «Мои заявки».
3. **Экран «Удостоверение личности»** — открывается по нажатию на карточку/строку «Удостоверение личности». Позволяет загрузить фото документа с телефона/компьютера. Фото сохраняется в `localStorage` браузера — оно останется после перезагрузки страницы.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
```

## Деплой на Vercel

1. Залей код в GitHub-репозиторий.
2. На vercel.com → Add New → Project → выбери репозиторий.
3. Настройки по умолчанию подходят (Vite определяется автоматически):
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

## Важно про сохранение фото

Фото хранится в `localStorage` того браузера, где было загружено — не отправляется на сервер, не видно другим пользователям. Это нормально для учебного проекта без бэкенда.
